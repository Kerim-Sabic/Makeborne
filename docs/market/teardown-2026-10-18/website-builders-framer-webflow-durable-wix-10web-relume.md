# AI website builders for designers, freelancers and small businesses: product teardown

Date: 2026-10-18. Scope: Framer, Webflow, Durable, Wix (Harmony / Studio), Hostinger AI Builder (ex-Horizons), 10Web, Relume. Pricing is deliberately excluded (reader already has a 13 Oct 2026 pricing table); it is mentioned only where the pricing *mechanism* shapes product behaviour or user complaints. Every non-obvious claim carries a URL. Where only vendor or agency-affiliated sources exist, that is flagged.

---

## 1. Framer

### End-to-end flow
- **Landing → start.** New project opens on a blank desktop homepage. Pre-3.0 the entry points were *Insert → Wireframer* (page generation from a prompt or a preset such as "personal page with a project list") and *Cmd+K → Workshop* (prompt-to-React-component). Wireframer auto-creates all breakpoints: "It even creates all the breakpoints automatically, so your site is responsive on desktop and mobile from the start" ([Framer University](https://framer.university/blog/the-new-ai-workflow-for-building-websites)). Third-party tests reported 30–60 s for a full page ([aibase](https://www.aibase.com/news/18288), [thedesignerreview](https://thedesignerreview.com/framer-ai-review-2026/)).
- **Framer 3.0 (16 Jun 2026)** folded this into **Framer Agents**: an Agent tab sits in the right panel next to Style, with a model dropdown (GPT/Sonnet/Opus/Fable), canvas layers pulled into chat as context, `@pages/@components/@styles` mentions, uploaded references (DESIGN.md, screenshots, CSV, URLs), slash commands (`/cms`, `/component`, `/code`), and **Skills** (reusable instructions such as `design-system`, `cms-content`, `remove-ai-writing`, `seo-check`) ([framer.com/wireframer](https://www.framer.com/wireframer/), [Framer Launches AI Agents](https://www.morningstar.com/news/business-wire/20260616909966/framer-launches-ai-agents), [Omakase 3.0 write-up](https://www.oma-kase.com/blog/framer-3-launch)). The agent shows a short plan first (demo: a four-step plan for a dark, minimal AI-research homepage, then offers tablet/phone breakpoints). It highlights the layers it touches, has a "Follow" button, **Revert undoes an entire prompt**, and every message is a rollback point.
- **Branching** is first-class: a "main" label on the canvas opens branches; "Apply to main" merges instantly. Framer Academy explicitly tells users to put any change that touches several pages, components, breakpoints or text/colour styles on a branch, and to review each breakpoint after agent edits ([Framer Academy lesson](https://www.framer.com/academy/lessons/framer-agents-generation-layout-style)).
- **Editor model**: free-form canvas with Stacks (flex), real breakpoints, Text Styles / Colour Styles, Components with variants, CMS collections, effects/scroll animations. Figma import is via the "Figma to HTML with Framer" plugin: Auto Layout → Stacks and text styles survive, but Figma's style library does not map to Framer's style system and component variants/interactions must be rebuilt ([Hedrick guide](https://hedrick.io/post/figma-to-framer-guide), [All About Framer](https://allaboutframer.com/how-to-seamlessly-import-figma-designs-to-framer)).
- **CMS (Sept 2026)**: new List field for repeating content (FAQs, steps) with a `Repeat` canvas property; inline editing for content editors; agent can convert existing fields ([framer.com/updates](https://www.framer.com/updates)).
- **Pre-publish**: the agent runs a review for contrast, typos, missing alt text, SEO gaps and inconsistent styles, and an analytics review (top pages, drop-offs, search intent) ([framer.com/wireframer](https://www.framer.com/wireframer/)). Hosting is bundled; Oct 2026 added a country/path **Firewall** (Advanced Hosting add-on or Enterprise) ([updates](https://www.framer.com/updates)).
- **External agents**: Claude Code, Cursor, Codex connect via Framer CLI/MCP, work on auto-created branches, and run on the user's own LLM tokens "without consuming your Framer AI Credits" ([Omakase](https://www.oma-kase.com/blog/framer-3-launch)).

### Client handoff and agency features
- **Project Transfers** (published Aug 2025): *File → Transfer Project*, enter client e-mail; the whole site "complete with a domain, forms, locales, and more" moves to the client's workspace with no downtime; the designer can stay on as editor ([framer.com/updates/project-transfers](https://www.framer.com/updates/project-transfers)). The older route was a **Remix link** the client duplicates into their own account, often with an affiliate code attached ([All About Framer](https://allaboutframer.com/how-to-handoff-a-framer-website-for-a-client-project), [Storylane](https://www.storylane.io/tutorials/how-to-transfer-projects-for-a-client-from-framer)).
- **Roles**: Editor (full) vs **Content Editor** (CMS, Localization, On-Page Editing only; no design canvas). May 27 2026: editors cut to $20/mo on all plans, content editors $10/mo ([Framer on X](https://x.com/framer/status/2059620408132071728), [Framer Help roles](https://www.framer.com/help/articles/member-roles-and-permissions/)). On-page editing lets a logged-in client click text/images on the live preview and edit in place.
- **Experts program** doubles as the billing model: experts earn up to 50% commission when a transferred client buys a plan; $500 of commissions makes you a **Pro Expert**, who joins client projects as a free full editor, gets directory priority and 50% off Agent credits ([Framer Help: become an Expert](https://www.framer.com/help/articles/how-to-become-a-framer-expert/), [expert/apply](https://www.framer.com/expert/apply/)). The agency pays nothing for staying on a client's site; the client pays Framer.
- **Review/approval**: there is no client approval workflow. Branching + Revert is the designer's safety net; the Reviewer/comment role that Webflow has does not exist in Framer.
- **Marketplace**: the pre-publish template review gate was removed with 3.0 ("Creators publish when they are ready. Moderation replaces reviewing"); Framer reports 7,000+ creators and $6.5M paid to creators in 2025 ([Omakase](https://www.oma-kase.com/blog/framer-3-launch), [Framer Help: publish a template](https://www.framer.com/help/articles/how-to-publish-a-template/)).

### How AI is used
Generative layout **inside the project's design system**: Academy guidance is to select the page/frame/component first and "mention the existing styles or nearby sections the Agent should follow" so output matches Text Styles, Colour Styles and Components. The agent also generates light/dark themes, componentises layers, writes copy, iterates images conversationally, builds CMS collections and code components ([Academy](https://www.framer.com/academy/lessons/framer-agents-generation-layout-style), [Omakase](https://www.oma-kase.com/blog/framer-3-launch)). Skills travel with remixed templates, so template authors can ship "how to add content" instructions to buyers ([updates](https://www.framer.com/updates)).

**Credits**: one credit = one operation at the base model; ~300 for a full landing page, ~150 for a responsive layout, ~100 large edit, ~50 small edit; Free 500/day, Basic 1,000/mo, Pro 3,000/mo; Opus-class models at 1.8x; a "Mark as Bad" option refunds credits ([Omakase](https://www.oma-kase.com/blog/framer-3-launch)).

### Quality and weaknesses
- Praise: "deterministic layout control, structured components, visual consistency and predictable spacing" ([lowcode.agency](https://www.lowcode.agency/blog/claude-vs-framer)); portfolios, SaaS and agency sites "consistently look sharper" than template-first rivals ([aitoolspolice](https://aitoolspolice.com/reviews/framer/)).
- Complaints: Trustpilot ~1.6/5 vs G2 4.5/5, attributed to billing/seat friction vs design praise ([aitoolspolice](https://aitoolspolice.com/reviews/framer/)). The 2025 repricing drew "You're outpricing yourself into oblivion" over 1 CMS collection on Basic and doubled editor seats ([All About Framer](https://allaboutframer.com/framer-pricing-explained-(2025)-the-good-the-bad-what-it-really-means-for-you)); May 2026 partially reversed this (2 collections, 50 GB, $20 seats) ([Omakase pricing](https://www.oma-kase.com/blog/framer-pricing-update-may-2026)). No code export → lock-in ("never rely on an asset you don't own"). Trustpilot DK reports AI rebuilding a simple request into "something completely different", hidden cancel button, GDPR/CDN concerns in Germany ([Trustpilot DK](https://dk.trustpilot.com/review/www.framer.com)). CMS caps make it unsuitable for 400+ article sites ([layer3labs](https://www.layer3labs.io/guides/framer-cms)).

### 2026 roadmap signals
Agents + Branching + MCP (June), Skills (Sept), CMS List fields (Sept), Firewall (Oct). Direction: Framer as the canvas that external coding agents target, with credits priced to fall over time ("design-grade AI tokens to become cheap or free sooner than most people expect").

## 2. Webflow

### End-to-end flow
- **AI Site Builder** (dashboard entry): answer a few setup questions, then Webflow "generates several complete site designs that fit your description", each with a homepage layout and a **style guide** (colours, fonts) ([lowcode.agency](https://www.lowcode.agency/blog/webflow-ai-features), [webflow.com/updates/ai-site-builder](https://webflow.com/updates/ai-site-builder)). Output is native Designer elements: pages, sections, placeholder copy, basic styling and responsive settings; "The output is a starting point, not a finished site" ([theCSS Agency](https://www.thecssagency.com/blog/webflow-ai-site-builder)).
- **AI Assistant** (Designer chat): generates and modifies **sections** "from your site's existing design system", does not consume credits, does not include components, images or dynamic data, and cannot generate individual elements ([Webflow Help](https://help.webflow.com/hc/en-us/articles/34205154436243-Modify-page-designs-with-the-Webflow-AI-Assistant)). Reviewers: it "rarely produces sites with clashing font weights or inconsistent button styles" but "defaults to standard Bootstrap-style grids" ([vibecoding.gallery](https://vibecoding.gallery/en/tools/webflow-ai/)); it "performed better at design than at copy" and failed most at positioning ([Memeburn](https://memeburn.com/webflow-review/)).
- **Editor model**: box-model/class-based Designer with variables, components, **Component Canvas** (edit all variants at once), **Code Components** (import React components, edit via props), GSAP engine with per-breakpoint animation control and `prefers-reduced-motion`, real-time multiplayer (default since Feb 2026, last-write-wins) ([Digidop Conf recap](https://www.digidop.com/blog/recap-of-webflow-conf-2025), [Milkmoon guide](https://www.milkmoonstudio.com/post/webflow-roles-seats-pricing-explained-2026-guide)).
- **AI app generation** ("similar to Lovable") deploys full-stack web apps to **Webflow Cloud**; **AI-assisted SEO** does one-click metadata, alt text and structured data; **Analyze & Optimize** adds conversion tracking and LLM traffic insights; forms now have per-form settings and an anti-spam inbox ([Digidop](https://www.digidop.com/blog/recap-of-webflow-conf-2025)).
- **Legacy Editor retired 4 Aug 2026**; CMS content is now edited in the Designer with role-scoped UI ([Milkmoon](https://www.milkmoonstudio.com/post/webflow-roles-seats-pricing-explained-2026-guide), [Webflow client seats](https://webflow.com/updates/client-seats)).

### Client handoff and agency features (the most complete in this set)
- **Roles**: Owner, Admin, Site Manager, Designer, Marketer (pre-approved components + content), Content Editor (text/images/links), Reviewer (comment-only; a shared comment link works without an account). Publish rights are toggled per role on Growth/Agency plans ([Milkmoon](https://www.milkmoonstudio.com/post/webflow-roles-seats-pricing-explained-2026-guide)).
- **Client Seats** (launched 2 Feb 2026): free, site-specific, Content Editor/Marketer/Reviewer; 1 per paid site on Starter, 1 per site on Freelancer, 3 per site on Agency; cannot be purchased beyond that ([webflow.com/updates/client-seats](https://webflow.com/updates/client-seats), [Sygnal](https://www.sygnal.com/lessons/client-seats)). **Guest seats**: 2 external agency teams of 5 on most plans.
- **Client payments**: client adds their own card and "Webflow invoices them for the Site Plan"; the agency never touches card data ([Milkmoon](https://www.milkmoonstudio.com/post/webflow-roles-seats-pricing-explained-2026-guide)).
- **Review**: comment-only links for people without an account (Conf 2025) are the closest thing to a review flow among the canvas tools ([Digidop](https://www.digidop.com/blog/recap-of-webflow-conf-2025)).
- **Watch-out**: "removing a team member doesn't automatically reduce your seat count".

### Quality and weaknesses
- **Pricing restructure (May 2026)**: 4 site tiers → 3; Basic monthly $18→$25; new $2,500/mo Team plan on annual contract "prices out mid-market buyers" ([growthmanager.ai](https://growthmanager.ai/compare/webflow), [thesmallsquare](https://www.thesmallsquare.com/post/webflow-pricing)). Migration of existing sites at renewal after 29 Jun 2026; Freelancer/Agency workspaces after 16 Nov 2026.
- **AI credits** enforced 29 Jun 2026: Free 200, Core/Freelancer 300, Growth/Agency 400 per month; heavy generative work (code components) burns credits, AI Assistant section edits and app building do not; no surprise overage—features simply stop ([EverythingFlow](https://www.everythingflow.agency/blog/webflow-ai-credits-explained)).
- "Hosting lock-in… migrating full projects out is still difficult" ([vibecoding.gallery](https://vibecoding.gallery/en/tools/webflow-ai/)). AI Site Builder "not suitable as a replacement for full design work on complex or brand-critical projects" ([theCSS Agency](https://www.thecssagency.com/blog/webflow-ai-site-builder)). Positioning: "The AI does not replace the canvas; it works alongside it… That control costs time" ([aiindigo](https://aiindigo.com/blog/2026-review-webflows-ai-site-builder)).

### Roadmap signals
Design-system-aware AI, code components as the extension model, Webflow Cloud for apps, Analyze/Optimize as the upsell, clients moved from a separate Editor into role-restricted Designer views.

## 3. Durable

### End-to-end flow
- Three onboarding questions: business type, name, location. "The AI picks the right template and fills it with content" in ~30 s ([cybernews](https://website-builders.cybernews.com/durable-ai-website-builder-review/), [Tooltester](https://www.tooltester.com/en/reviews/durable/)). The 17 Mar 2026 relaunch ("the complete AI business builder for independent entrepreneurs") claims "No stock photos, no templates to fill in", business-specific generated images, user-chosen fonts/colours kept consistent across pages, and new pages generated from a text description that match the existing site ([durable.com/blog/launch](https://durable.com/blog/launch)).
- **Editor**: section-based; "You cannot freely move elements or adjust layouts"; max 20 sections per page; global colours/fonts only; AI adds a contact form whose fields you can remove but not add ([Tooltester](https://www.tooltester.com/en/reviews/durable/)). Hands-on: "the design options felt limited. I wanted to move sections around more freely"; templates "look similar across industries" ([fahimai](https://www.fahimai.com/durable-ai)).
- **Publish**: durable.site subdomain free; custom domain on paid tiers; basic SEO fields (slug, title, meta) but no schema/301s; GA via custom code; Stripe payment links instead of a cart; no member areas, no backups, no multilingual ([Tooltester](https://www.tooltester.com/en/reviews/durable/)).
- **Business layer**: light CRM synced to the contact form, Stripe invoicing with payment links on the branded site, **AI Partner** (chat assistant that reads contacts/invoices/goals), **Studio** (logos, social posts, posters, headshots), **Blog Agent** (27 May 2026) that plans/drafts/schedules posts, LLMs.txt + Markdown on every site, SEO/GEO tools (directory listings, Google Business Profile, rank tracking) ([durable.com/blog/launch](https://durable.com/blog/launch), [Durable pricing analysis](https://ploy.ai/blog/durable-pricing)).

### Client/agency features
None. Durable is owner-operated; reviewers describe the CRM as "basic compared to dedicated tools" and useful mostly for solo operators ([we.inc](https://we.inc/blog/durable-ai-website-builder-review)). No white-label, transfer or review flow found.

### Quality and weaknesses
Tooltester 3.6/5; Product Hunt 3.8. Consistent complaints: limited design control, no real ecommerce, few integrations, AI content accuracy ([TechRadar](https://www.techradar.com/pro/software-services/durable), [websiteplanet](https://www.websiteplanet.com/website-builders/durable/)). Why it looks generic: one layout grammar per business category, section library of fixed blocks, global theme only, and the AI's job is to *fill* rather than *compose*.

## 4. Wix (Harmony and Studio)

### Wix Harmony (consumer/SMB; launched 21 Jan 2026)
- Flow: prompt (with a "refine my prompt" button), template, or blank canvas → **Aria** introduces itself, plans, builds with a right-hand sidebar explaining "what Aria was building and why" (compared to Lovable's transparency); first design in "a few minutes" ([Website Builder Expert](https://www.websitebuilderexpert.com/news/wix-harmony-launch/), [Wix press release](https://www.wix.com/press-room/home/post/wix-launches-wix-harmony-the-ai-website-builder-that-merges-human-and-artificial-intelligence-rein)).
- Aria is persistent in the editor (not a one-shot generator), understands full site context, generates a site/page/section, and can produce native custom components with logic; Wix claims changes in one area "do not break the code" elsewhere. Hybrid editing: prompt a section, then drag-and-drop fine-tune ([press release](https://www.wix.com/press-room/home/post/wix-launches-wix-harmony-the-ai-website-builder-that-merges-human-and-artificial-intelligence-rein), [Digital Applied](https://www.digitalapplied.com/blog/wix-harmony-ai-website-builder-natural-language-creation)). Other agents: Kleo (marketing/SEO), Juno (customer service), Omni (inventory) ([SEJ](https://www.searchenginejournal.com/wix-introduces-harmony-ai-website-builder/565505/)).
- Weaknesses: "the results felt generic… the same fonts, colours and sections came up across tests" ([flowcre8tive](https://www.flowcre8tive.com.au/post/is-wix-harmony-good-for-small-businesses-we-tested-it-to-find-out)); "the AI fights you for control"; auto-responsiveness breaks pixel-precise brand rules; "many Wix Blocks apps and third-party widgets are NOT compatible yet" ([Busigner](https://www.busigner.com/post/wix-harmony-review-limitations)); fewer manual controls than Classic/Studio, missing CMS/dynamic pages/dev mode ([vibecompare](https://vibecompare.dev/tools/wix-harmony/)); code hidden and inaccessible ([thewixwiz](https://www.thewixwiz.com/post/wix-harmony-review-the-future-of-ai-powered-website-building)). Praise: hostadvice 9.2 and "the strongest AI-generated copy of any website builder tested" ([hostadvice](https://hostadvice.com/hosting-company/wix-com-reviews/wix-com-harmony-review/)).

### Wix Studio (agency product)
- AI today: responsive AI layout adjustments, AI copy, AI image/video, AI code assistant, AI sitemap/wireframe generation ([wix.com/studio/for-agencies](https://www.wix.com/studio/for-agencies)).
- **Studio 2 (preview; rollout "late summer"/"end of 2026")**: dark on-canvas editor, **Plan Mode** that turns discovery inputs (business details, audience, brand preferences, structure) into a brief before design, **Aria 2.0**, **AI Skills** (agencies save spacing/typography/padding/brand rules as reusable instructions), new projects start with only desktop + mobile breakpoints with mobile auto-generated, global styles propagate sitewide ([DLL Studios](https://www.dllstudios.com/post/wix-studio-2-first-look-future-professional-website-design)).
- **Handoff**: two paths. (a) Invite as collaborator and mark as **Client**; content-only permission "lets them take control of their own content, without risking the integrity of your design"; collaborators can comment in the editor but cannot delete/transfer. (b) **Transfer site** moves the Premium plan, domain, mailboxes and optionally premium apps; agency keeps Co-Owner role; client must accept within 3 days; the new owner can revoke the agency at any time; staying connected preserves partner points ([Wix Studio Academy handover](https://www.wix.com/studio/academy/tutorials/how-to-handover-your-site-to-clients)).
- **Client Kit**: per-site package of uploaded files, Wix tutorial videos and optional agency contact details, visible read-only in the client's dashboard; editable after sharing ([Wix support](https://support.wix.com/en/article/wix-studio-creating-a-client-kit-5293562)). Also automated client reports, mobile agency app, Customer Care tickets ([Studio FAQs](https://support.wix.com/en/article/wix-studio-faqs-using-the-workspace)). Known pitfall: after transfer the client sometimes cannot edit at all ([Wix Studio forum](https://forum.wixstudio.com/t/my-client-can-not-edit-the-website/54137)).
- Review/approval: comments only; no approval gate.

## 5. Hostinger AI Builder (ex-Horizons)

- **Merge 18 Aug 2026**: Horizons (chat/vibe-coding) and the drag-and-drop Website Builder became one product with two modes. **Manual mode**: visual editor, no credits, 400+ templates, "best for small to medium sites". **Agentic mode**: chat builder with code editor, built-in backend, auth, Stripe subscriptions, "virtually any API-based integration"; each action costs credits (simple business page 5–10, complex app 15+) ([hostinger.com/horizons](https://www.hostinger.com/horizons), [vibecoding.app](https://vibecoding.app/blog/hostinger-horizons-review)).
- Hands-on (Jan 2026, pre-merge): an 870-word PRD produced a prototype in ~10 min; Horizons asked two clarifying questions (both about the database) which cost nothing; every backend feature was initially broken; the tester pasted 29 SQL queries into Supabase and quit at 68 of 200 credits with the app unfinished: "With Horizons, this was impossible" to estimate remaining work ([allaboutcookies](https://allaboutcookies.org/hostinger-horizons-review)). Click-to-isolate an element then type an instruction; manual WYSIWYG mode saves credits.
- Publish: one-click deploy, hosting + SSL + CDN + mailboxes bundled, free domain year on annual plans, full source export, but "if hosting lapses… data is permanently deleted" ([hostinger.com/horizons](https://www.hostinger.com/horizons)). Models cited: Gemini 3 and Claude Sonnet 4.5 ([cybernews](https://cybernews.com/ai-tools/hostinger-horizons-review/)).
- Agency features: none on the product page. Weaknesses: "no clean export path" pre-merge, Node-only stack, complex multi-screen apps "outgrow it quickly" ([codingwithvibe](https://codingwithvibe.com/hostinger-horizons-review/)). Design quality is not the pitch; functional output is ("forms that submit, navigation that works") ([agent-finder](https://agent-finder.co/reviews/horizons-hostinger-ai-website-builder-)).

## 6. 10Web

- Flow: free-text prompt (business name + type), optional images or Figma import → "Setting up your project… Configuring hosting… Installing WordPress backend… Preparing builder environment" → full WordPress site with layout, text, images in "under a minute"; can also build WooCommerce stores; models from OpenAI, Gemini and Anthropic ([10web.io/ai-builder](https://10web.io/ai-builder/), [10Web press release](https://10web.io/press-kit/press-release-ai-website-builder-wordpress-hosts/)). URL-recreate copies homepage + up to ~4 pages (older test) ([learningrevolution](https://www.learningrevolution.net/10web-io-review/)).
- Editor: **Elementor** with 50+ custom widgets; **AI Co-Pilot** chat edits pages/widgets/sections (auto-enabled for sites generated after Nov 2024) but "for complex customizations, you'll still need to use the traditional editor" ([10Web Help](https://help.10web.io/hc/en-us/articles/23970145055122-Co-Pilot-Editor), [durable.com/ai-tools/10web](https://durable.com/ai-tools/10web)).
- **Agency/white-label**: Agency Starter (~10 sites) and Core tiers with client billing through Stripe/PayPal; Core charges a 7% fee on client billing; branded dashboard + builder on Core and up; full reseller white-label (host's name, logo, colours across builder, generation, editing and WP dashboard, delivered as a plugin via WP Toolkit/WHM/Plesk) is quote-only ([10web.io/pricing-platform](https://10web.io/pricing-platform/), [we.inc](https://we.inc/blog/best-white-label-website-builders-2026), [press release](https://10web.io/press-kit/press-release-ai-website-builder-wordpress-hosts/)). 10Web claims hosted users were 30% more likely to publish.
- Weaknesses: auto-renewals without warning and refused refunds dominate Trustpilot/Capterra ("$300 had been taken from my account"); "You cannot really transfer anything you build here"; AI content "unpolished, generic… requires heavy editing" ([Trustpilot](https://www.trustpilot.com/review/10web.io), [Capterra](https://www.capterra.com/p/186678/10Web/reviews/), [G2](https://www.g2.com/products/10web/reviews)). Output looks like Elementor because it is Elementor.

## 7. Relume

### Core workflow (Export product)
Brief (a few sentences) → **sitemap** (pages + relations) → one-click **low-fi wireframes** assembled from the 1,000+ component library → **Style Guide Builder** (AI proposes brand/accent/neutral colours and Google Fonts pairings; each section gets colour schemes; **Design View** applies the style guide sitewide) → **Pitch Concepts** (side-by-side variations with a shareable link for client feedback) → export to Figma (plugin, with local styles and real components), Webflow (Client-First class system by Finsweet) or React/HTML (Tailwind + shadcn) ([Relume docs: Style Guide](https://resources.relume.io/resources/docs/concept-creation-using-the-relume-style-guide-builder), [Digidop](https://www.digidop.com/blog/tool-generation-style-guide-with-ai-replaces-designer), [relume.ai/whats-new](https://www.relume.ai/whats-new)). Copywriting 1.5 (Sep 2025) runs on Claude for whole-page consistency; Wireframing 2.0 widened component access and "brand alignment".

### Relume Publish (Beta, 24 Aug 2026) — the pivot to hosting
- "AI that assembles, not generates": the **Smart Project Brief** ingests a client's Notion doc, brand files, URL or recordings and keeps updating with analytics; AI selects human-made components, plans structure, applies design, writes copy. **Relumify** pastes an existing URL and rebuilds "content, images, structure and brand, mapped to real components". Edits are component swaps and sitewide restyles, not prompts. Four post-launch agents (Strategist, Designer, Copywriter, Analyst) read built-in analytics and *propose* campaign pages, CTA changes, SEO fixes: "They propose, you decide." Cloudflare edge hosting, 99.99% SLA, one-click publish; relume.live subdomain "for drafts and client review"; **unlimited free editors including clients** ([Publish beta](https://www.relume.ai/whats-new/relume-publish-has-landed-in-beta), [Relume pricing page features](https://www.relume.ai/pricing), [Relume on X](https://x.com/relume_ai/status/2092344512207048726)).
- **Publish MCP (14 Oct 2026)**: build/publish/update a Relume site from Claude or ChatGPT; demo reads a Notion questionnaire and Drive brand assets, emails the live link via Gmail; a bundled skill rebuilds the site in Webflow via Webflow's MCP following Client-First ([Publish MCP](https://www.relume.ai/whats-new/relume-publish-mcp)). Earlier in 2026: Relume design system export to Claude Design (May), Library MCP for Cursor/Claude/VS Code (July).
- Agency/client: Branded Sharing (logo on previews), view-and-comment sharing on paid tiers, custom-branded sharing on Team, private sharing caps 3/5/unlimited; Publish is "the cheaper way to pay from two people up, because editors cost nothing per seat" ([saascrmreview](https://saascrmreview.com/relume-review/)). No approval gate beyond comments.
- Weaknesses: free-plan test produced "no images generated, and the logo slots left empty"; "cookie-cutter" risk from heavy library reliance ([tooliverse](https://tooliverse.ai/tools/relume)); some React components "broken or missing in the export" ([Relume community](https://community.relume.io/x/feedback/msg_6dPUoO8K6x2d/relumes-real-edge-is-getting-from-components-to-a)).

## Cross-cutting lessons for a competitor (Makeborne)

1. **Constrain generation to a design system, then let AI compose within it.** The three products designers respect (Framer, Webflow, Relume) all generate *from* existing Text/Colour Styles, classes or a curated component library; Webflow's assistant literally refuses to invent elements. Durable, Wix Harmony and 10Web generate freely and are the ones called "generic". Makeborne's generator should take a brand kit + section vocabulary as hard inputs, not as hints.
2. **Plan before pixels, and show the plan.** Framer shows a four-step plan; Wix Harmony's sidebar explains "what Aria was building and why"; Wix Studio 2 adds a Plan Mode brief; Relume's Smart Project Brief is the persistent source of truth. Users trust output more when they see the reasoning and can edit the brief, not the result.
3. **Make the brief a living object fed by client intake.** Relume ingests Notion docs, recordings and URLs and later analytics; Studio 2 pulls discovery into a brief. Makeborne already has a CRM — the client record *is* the brief. Nobody else closes that loop natively.
4. **"Relumify" is the fastest sales motion for agencies.** URL → rebuilt site on your components (Relume), URL → recreate (10Web), URL as reference (Framer, Hostinger). A "paste the client's current site" entry point converts prospects better than a blank prompt and seeds brand colours/copy automatically.
5. **Whole-prompt revert + branches are the safety model designers accept.** Framer's per-message rollback, "Apply to main", and "Mark as Bad" credit refund make agent edits reversible; Relume's per-site version history does the same. Without this, pros will not let AI touch a client site.
6. **Role-scoped client editing beats "share the editor".** Every serious tool has converged on a content-only client role (Webflow Client Seat/Content Editor, Framer Content Editor + On-Page Editing, Wix content-mode "Client", Relume free editors). The differentiators are: free for clients (Webflow, Relume) vs paid (Framer $10), and on-page editing on the live preview rather than a CMS table.
7. **Nobody has a real approval flow.** Webflow has comment-only links, Wix has editor comments, Relume has view-and-comment sharing, Framer has none. A review link with per-section approve/request-changes and a locked "approved" state is open territory and matches Makeborne's review-link positioning.
8. **Let the client pay the platform directly, and pay the agency a commission.** Webflow client payments (client's card, Webflow invoices), Framer Experts (up to 50% commission, free editor seat after transfer), 10Web Stripe/PayPal client billing (7% fee). Transfer-of-ownership with the agency staying on as a free collaborator is table stakes; Framer's commission model is what makes freelancers evangelise it.
9. **Credits must map to visible operations.** Framer publishes per-operation costs (~300 landing page, ~50 small edit) and refunds bad results; Hostinger charges nothing for clarifying questions or manual edits; Webflow makes section edits free and only meters heavy generation. The Hostinger tester's complaint was not price but unpredictability ("impossible" to estimate remaining credits). Publish a cost preview before each generation.
10. **Agent-level pre-publish checks are now expected.** Framer checks contrast, typos, alt text, SEO, inconsistent styles; Relume runs pre-publish checks; Webflow one-clicks metadata/alt/structured data. Ship a QA pass that produces a client-visible checklist — it doubles as a deliverable in the handoff.
11. **Reusable "Skills" are how agencies encode taste.** Framer Skills (design-system, remove-ai-writing, seo-check) travel with remixed templates; Wix Studio 2 "AI Skills" store spacing/typography/brand rules. Makeborne should let an agency define house rules once and apply them across websites, decks and books.
12. **Be an MCP target, not just a chat UI.** Framer (Claude Code/Cursor/Codex on branches, on the user's own tokens), Relume (Library MCP, Publish MCP with Webflow handoff skill), Webflow MCP. Agencies increasingly orchestrate from Claude/ChatGPT; exposing Makeborne's brief/sitemap/publish as MCP tools costs little and removes the "another tab" objection.
13. **Fixed section grammars create the "same site" problem; variety must be explicit.** Wix Harmony testers saw "the same fonts, colours and sections" repeat; Durable templates "look similar across industries"; Webflow AI "defaults to standard Bootstrap-style grids". Generate N distinct art directions (Webflow's "several complete site designs", Relume's Pitch Concepts) and vary type pairing, density and image treatment per direction, not just colour.
14. **Lock-in and renewal shocks are the loudest complaints in every review set** (Framer no export; 10Web auto-renewals; Hostinger data deletion when hosting lapses; Webflow Team at $2,500/mo). A clean export and honest renewal e-mails are differentiators that cost almost nothing.
15. **Design-quality tools win reviews; business tools win retention.** Durable keeps SMBs with CRM + invoicing + blog agent despite a 3.6 design score; Framer wins designers but bleeds on Trustpilot over billing. Makeborne's combination (CRM + review links + publishing + decks/books) is closer to Durable's retention model with Framer-class output — that pairing does not exist yet.

### What makes a generated site look designed, per these products
- **Framer**: output is composed from the project's Text Styles, Colour Styles and Components (agent instructed to "follow nearby sections"); real breakpoints generated and reviewed; Stacks give predictable spacing; motion/scroll effects presets; light/dark theme generation; Figma import brings designer-made layouts in as Stacks; a 7,000-creator marketplace supplies curated starting points; pre-publish consistency check flags "inconsistent styles".
- **Webflow**: section generation reads the existing class/variable system so "font weights and button styles" never clash; AI Site Builder emits a style guide alongside the homepage; Component Canvas keeps variants coherent; GSAP per-breakpoint motion. Cost: conservative grid layouts.
- **Relume**: 1,000+ human-designed, breakpoint-tested components; style guide with per-section colour schemes (background/foreground/text/border as a unit); Client-First class naming; Design View applies the system sitewide; Claude-based whole-page copy consistency. "Assembles, not generates" is the thesis — and the cookie-cutter risk is the price.
- **Wix Harmony/Studio**: Aria uses designer-made templates and Wix's component architecture so edits don't break; Studio 2 adds global styles that propagate and auto-generated mobile; but auto-responsiveness overrides precise brand placement and the same palettes/sections recur.
- **Durable**: one template per category filled with AI copy/images; global fonts/colours only; fixed 20-section blocks → clean, responsive, interchangeable.
- **Hostinger**: functional-first vibe coding; polish comes from templates in manual mode; no design-system layer.
- **10Web**: Elementor widgets + 10Web theme; looks like Elementor; quality depends on the user editing in Elementor afterwards.

The common denominator of "designed": a bounded vocabulary of good components, a typed style system (type scale, colour roles, spacing tokens) the generator must obey, explicit breakpoints that are generated *and* reviewed, and copy generated with page-level context rather than per block.
