# UI/UX audit — 2026-10-13 (Claude)

**Method.** I used a local production build against the isolated release stack: `node scripts/local-release-server.mjs build|start 3058`, with all provider keys blanked. I signed in as the local quality-test administrator. I checked every page at desktop width (966px) and phone width (375px).

On each page an automated audit script checked:
- horizontal overflow;
- controls without accessible names, unlabelled fields, duplicate IDs, images without alt text;
- small tap targets on phones;
- text under 12px;
- visible focus with real Tab presses;
- running animations;
- console errors.

I also made manual clicks and read screenshots.

**Limits.**
- No AI generation was run (no keys; paid calls are not authorized).
- Google/GitHub sign-in and real email delivery were not exercised here; Codex verified them on staging.
- Contrast was checked by eye, not measured.
- The home page was left as the owner likes it. Only shared components changed (see "Effort slider").
